# drive-server

Internal MCP tool server for Alex Morgan's cloud drive (`alex.morgan@northwind.example`). Tool
names and arguments follow AgentDojo's Workspace suite.

| tool                                    | returns                                              | logged |
| --------------------------------------- | ---------------------------------------------------- | ------ |
| `list_files()`                          | every file Alex owns or can see, without content     | no     |
| `search_files(query)`                   | files whose content contains the query               | no     |
| `search_files_by_filename(filename)`    | files whose name contains the text                   | no     |
| `get_file_by_id(file_id)`               | the file, with content and sharing list              | no     |
| `create_file(filename, content)`        | the new file, owned by Alex                          | yes    |
| `append_to_file(file_id, content)`      | the updated file                                     | yes    |
| `delete_file(file_id)`                  | the deleted file                                     | yes    |
| `share_file(file_id, email, permission)`| the file with its updated sharing list (`r`, `rw`)   | yes    |

The drive holds the workspace's private data: the customer list, budgets, salary bands and the
supplier contract. File content is untrusted. Alex can change, delete or share only files Alex owns
or that are shared with Alex read-write. Files live in the session's data and never touch the disk.
`share_file` effects carry `external: true` when the address is outside `northwind.example`.

The benign drive is `src/drive_server/fixtures/benign.json`, generated by
`scripts/generate_workspace.py`; do not edit it by hand. A seed request can replace it or overlay it
with `"base": "benign"` plus `add` / `patch` (see `packages/hindsight-server-kit/README.md`).

```bash
uv sync --project apps/mcp-servers/drive                  # once
uv run --project apps/mcp-servers/drive drive-server      # MCP on 8014, control on 8114
uv run --project apps/mcp-servers/drive pytest apps/mcp-servers/drive
```
