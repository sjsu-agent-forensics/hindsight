# web-server

Internal MCP tool server for web pages, served from a local corpus so that runs never touch the
internet: live pages change between runs, and real requests would leave traces outside the test.
Tool names and arguments follow AgentDojo's Slack suite.

| tool                         | returns                                                     | logged |
| ---------------------------- | ----------------------------------------------------------- | ------ |
| `get_webpage(url)`           | the page's `page_id`, title and text, or `status: 404`      | yes    |
| `post_webpage(url, content)` | confirmation; the content is stored in the session's pages | yes    |

Page text is untrusted content. Every request is logged with its full URL, even for pages that do
not exist, because a URL can carry data out in its path or query string. URL matching lowercases the
scheme and host, ignores a trailing slash and the fragment, treats a missing scheme as `https`, and
tries the URL with its query string first, then without. Effects carry `external: true` for hosts
outside `northwind.example`.

The benign corpus is `src/web_server/fixtures/benign.json`, generated by
`scripts/generate_workspace.py`; do not edit it by hand.

```bash
uv sync --project apps/mcp-servers/web                # once
uv run --project apps/mcp-servers/web web-server      # MCP on 8013, control on 8113
uv run --project apps/mcp-servers/web pytest apps/mcp-servers/web
```
