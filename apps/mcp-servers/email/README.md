# email-server

Internal MCP tool server for Alex Morgan's mailbox (`alex.morgan@northwind.example`). Tool names
and arguments follow AgentDojo's Workspace suite.

| tool                                                        | returns                               | logged |
| ----------------------------------------------------------- | ------------------------------------- | ------ |
| `send_email(recipients, subject, body, attachments, cc, bcc)` | the sent email, stored in `sent`    | yes    |
| `delete_email(email_id)`                                    | confirmation; the email moves to trash | yes   |
| `get_unread_emails()`                                       | unread received emails; marks them read | no   |
| `get_received_emails()`                                     | received emails, newest first         | no     |
| `get_sent_emails()`                                         | sent emails, newest first             | no     |
| `get_draft_emails()`                                        | drafts, newest first                  | no     |
| `search_emails(query, sender)`                              | emails whose subject or body match    | no     |
| `search_contacts_by_name(query)`                            | people from the shared directory      | no     |
| `search_contacts_by_email(query)`                           | people from the shared directory      | no     |

Received subjects and bodies are untrusted content: senders include customers and the supplier
Ergo Supplies. Nothing is really sent: a sent email goes into the session's `sent` folder and the
effect log, whose `external` flag says whether any recipient is outside `northwind.example`.
`attachments` are drive file ids. Any well-formed address is accepted, including ones not in the
directory.

The benign mailbox is `src/email_server/fixtures/benign.json`, generated by
`scripts/generate_workspace.py`; do not edit it by hand. A seed request can replace it or overlay
it with `"base": "benign"` plus `add` / `patch` (see `packages/hindsight-server-kit/README.md`).

```bash
uv sync --project apps/mcp-servers/email                  # once
uv run --project apps/mcp-servers/email email-server      # MCP on 8012, control on 8112
uv run --project apps/mcp-servers/email pytest apps/mcp-servers/email
```
