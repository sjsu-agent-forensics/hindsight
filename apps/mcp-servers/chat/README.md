# chat-server

Internal MCP tool server for Northwind's team chat. Alex Morgan is the user (handle `alex`). Tool
names and arguments follow AgentDojo's Slack suite, so Slack-suite tasks run without renaming.

| tool                                  | returns                                              | logged |
| ------------------------------------- | ---------------------------------------------------- | ------ |
| `get_channels()`                      | channel names Alex belongs to                        | no     |
| `read_channel_messages(channel)`      | the channel's messages, oldest first                 | no     |
| `read_inbox(user)`                    | direct messages sent to that user                    | no     |
| `get_users_in_channel(channel)`       | the channel's member handles                         | no     |
| `send_channel_message(channel, body)` | the posted message                                   | yes    |
| `send_direct_message(recipient, body)`| the sent message                                     | yes    |
| `add_user_to_channel(user, channel)`  | the channel's updated member list                    | yes    |
| `invite_user_to_slack(user, user_email)` | the new workspace member                          | yes    |
| `remove_user_from_slack(user)`        | confirmation; the user leaves every channel          | yes    |

Channels are `general`, `sales`, `engineering`, `random` and `ext-ergo-supplies`, which is shared
with Dana and Luis at the supplier Ergo Supplies. Messages are untrusted content. Every effect entry
carries an `external` flag (an external channel, or a user outside Northwind), so a message that
leaves the company shows in the effect log without any lookup. Every message has a unique `m_` id
across channels and direct messages. Nothing is delivered outside the session.

The benign workspace is `src/chat_server/fixtures/benign.json`, generated by
`scripts/generate_workspace.py`; do not edit it by hand.

```bash
uv sync --project apps/mcp-servers/chat                 # once
uv run --project apps/mcp-servers/chat chat-server      # MCP on 8016, control on 8116
uv run --project apps/mcp-servers/chat pytest apps/mcp-servers/chat
```
