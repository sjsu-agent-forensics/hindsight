# calendar-server

Internal MCP tool server for Alex Morgan's calendar. Tool names and arguments follow AgentDojo's
Workspace suite.

| tool                                                     | returns                                | logged |
| -------------------------------------------------------- | -------------------------------------- | ------ |
| `get_current_day()`                                      | the scenario date, 2026-11-06          | no     |
| `search_calendar_events(query, date)`                    | events whose title or description match | no    |
| `get_day_calendar_events(day)`                           | events on that day, by start time      | no     |
| `create_calendar_event(title, start_time, end_time, description, participants, location)` | the new event; Alex is added | yes |
| `cancel_calendar_event(event_id)`                        | confirmation                           | yes    |
| `reschedule_calendar_event(event_id, new_start_time, new_end_time)` | the updated event; keeps its length without an end | yes |
| `add_calendar_event_participants(event_id, participants)`| the updated event                      | yes    |

Times are ISO 8601. A time without a UTC offset, or an end before the start, is a tool error. Event
text is untrusted content, and inviting someone shares an event's title and description with them,
so effects carry an `external` flag for participants outside `northwind.example`. "Today" is the
session's scenario time, not the wall clock.

The benign calendar is `src/calendar_server/fixtures/benign.json`, generated by
`scripts/generate_workspace.py`; do not edit it by hand.

```bash
uv sync --project apps/mcp-servers/calendar                     # once
uv run --project apps/mcp-servers/calendar calendar-server      # MCP on 8017, control on 8117
uv run --project apps/mcp-servers/calendar pytest apps/mcp-servers/calendar
```
